
# VibeFlow Landing Page

The landing page for VibeFlow, an independent music interface project built around discovering and exploring album artwork.

## Related Projects

* **Live app:** https://vibeflow-ecru.vercel.app
* **GitHub repository:** https://github.com/av1452/vibeflow
* **Creator portfolio:** https://myportfolio-sigma-one-55.vercel.app

## Tech Stack

* Next.js
* React
* TypeScript
* Tailwind CSS

## Getting Started

From this directory, install the dependencies and start the development server:

```bash
npm ci
npm run dev
```

Open http://localhost:3000 to view the landing page.

## Build

To create and verify a production build, run:

```bash
npm run build
```

To run the production build locally:

```bash
npm run start
```

## Project Structure

* `app/page.tsx` — landing page
* `app/components/AlbumShowcase.tsx` — interactive album artwork showcase
* `app/globals.css` — global styles
* `app/layout.tsx` — root layout and metadata
* `app/icon.svg` — site icon
